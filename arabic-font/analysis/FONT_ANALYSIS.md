# تحليل الأسلوب المرجعي (المرحلة ١–٢)

**القرار:** خط أصلي مقارب في الأسلوب، لا نسخة من أي خط تجاري. الصور المرجعية تُستخدم لفهم الخصائص العامة فقط، ولا تُتتبَّع حدودها.

## الخصائص العامة المستخلصة (أفكار أسلوبية لا مِلكية)
| الخاصية | الوصف |
|---|---|
| الأساس | نسخ حديث بتباين عالٍ بين الخط العريض والرفيع، مع سيريف مرتبطة بالقلم العريض |
| زاوية القلم | ثابتة تقريباً (~50–60°)، تعطي الكتل المائلة وتدرّج السماكة |
| النقاط | معيّنات (مربعات مائلة 45°)، وهي أسلوب شائع في الكوفي والنسخ المعاصر |
| الألف واللام | رأسان متسعان قليلاً وساق عمودية |
| النهايات | أطراف مدببة في الذيول (ب ن ق ل) وجذوع حادة في الحاء والدال |
| الاتصال | خط أساس مستقيم والكشيدة امتداد أفقي من الاتصال، لا تمديد للحرف نفسه |
| اللاتيني المصاحب | سيريف انتقالية بتباين متوسط (اختياري ومؤجل) |

## الحروف المبنية في النموذج الأول (أشكال منفصلة فقط)
ا ب ل م ع ح ق ن د و، وهي نماذج أولية للتحقق من الأسلوب وليست نهائية.

## مشاكل معروفة في النموذج الأول v1
- حلقتا م و ق (والواو) تنغلق فتحتهما الداخلية لأن سماكة القلم كبيرة بالنسبة لقطر الحلقة. تُعالج بمسار عين مفتوح أو تصغير السماكة داخل الحلقة.
- نقاط ق مربعة غير مائلة بالقدر الكافي.
- لا يوجد اتصال ولا خط أساس ولا تشكيل بعد.
- الإخراج حالياً مضلعات (مقاطع مستقيمة)، وسيحتاج لتحويل لاحق إلى منحنيات Bézier نظيفة قبل بناء الخط.

## ما لم يُنجز بعد
الأشكال الأولية والوسطى والنهائية، الكشيدة، الأوزان، محوري wght وwdth، التشكيل، GSUB/GPOS، ملف الخط نفسه.
