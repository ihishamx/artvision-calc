# artvision-calc — صفحات هبوط آرت فيجن (الحاسبة + الدفع)

صفحات هبوط ART VISION على `go.artvisionksa.com`. العميل يكتب المقاس الذي يريده فيظهر السعر فورًا، ثم يدفع عبر بوابة Tap. الاستضافة على Cloudflare Pages، وخارج متجر سلة.

> هذا المستودع ليس المتجر. المتجر على سلة (`artvisionksa.com`) ولا يُعدَّل من هنا.

## المحتوى

| المسار | الوصف |
|---|---|
| `public/` | الموقع كله، وهو المجلد الذي ينشره Cloudflare Pages |
| `public/_worker.js` | الخادم (Cloudflare Worker) بوضع Advanced. يخدم `/api/*` فقط ويمرّر الباقي للملفات الثابتة |
| `public/index.html` | الصفحة الجذر (الصفحة القديمة، قرارها عند Art) |
| `public/abstract/gold-leaf.html` | صفحة الطقم التجريدي بلمسات الذهب (3 لوحات) |
| `public/terms.html` `refund.html` `privacy.html` | الشروط والاستبدال والخصوصية |
| `public/fonts/` `public/images/` | خط ثمانية سانس والصور والفيديو |
| `public/_redirects` `_headers` `_routes.json` | التحويلات والترويسات وتحديد ما يمرّ على الـWorker |
| `public/sitemap.xml` `robots.txt` `llms.txt` | ملفات الفهرسة |
| `pricing-core.mjs` | **مصدر السعر الوحيد** (المعادلة والحدود) |
| `config.mjs` | المنتجات المسموحة وألوان البرواز والحدود |
| `tap.mjs` | عميل Tap (إنشاء الدفعة، قراءة الحالة، التحقق من الـwebhook) |
| `server.mjs` `index.mjs` `item-store.mjs` `salla-admin.mjs` | نسخة خادم Node (مسار سلة/Render). **غير مستخدمة في النشر الحالي على Cloudflare** |
| `*.test.mjs` | الاختبارات (`node --test`، 70 اختبارًا تمر) |

ملاحظة: `public/_worker.js` يُولَّد من `pricing-core.mjs` و`config.mjs` و`tap.mjs`. لا تعدّله يدويًا؛ عدّل المصدر ثم أعد التوليد.

مجلد `public/update2/` نسخة جانبية قديمة، يُراجَع قبل الاعتماد عليه أو حذفه.

## التسعير (إقرار Art P18، 7 أكتوبر 2026)

- **بإطار:** `(الطول × العرض × 400 ÷ 10000) + 25`
- **بدون إطار:** `((الطول + 4) × (العرض + 4) × 200 ÷ 10000) + 25`، والـ +4 سم داخلي ولا يظهر للعميل ولا يمسّ المقاس المعروض.
- الكسر يُرفع إلى الريال الأعلى مرة واحدة لكل لوحة، والطقم = سعر اللوحة × 3.
- الـ 25 ريالًا مضمّنة في السعر ولا تُعرض كشحن.

الحدود على المقاس المُدخَل (بالسنتيمتر):

| الحالة | الحد |
|---|---|
| الأدنى | 20 × 20 |
| بإطار | الطول ≤ 290 والعرض ≤ 150 |
| بدون إطار | الطول ≤ 330 والعرض ≤ 150 |

السعر في المتصفح للعرض فقط. الخادم يعيد حسابه عند الدفع ولا يثق بما يرسله المتصفح.

## واجهات الخادم (`/api/*`)

| المسار | الوظيفة |
|---|---|
| `GET /api/health` | فحص الجاهزية (هل مفتاح Tap مضبوط) |
| `POST /api/tap/checkout` | يعيد حساب السعر وينشئ دفعة في Tap ويعيد رابط الدفع |
| `GET /api/tap/status` | حالة الدفعة بعد العودة من Tap |
| `POST /api/tap/webhook` | إشعار Tap بنتيجة الدفع |

الدفع بصفحة Tap المستضافة (`src_all`). بعد الدفع يعود العميل إلى `/?paid=1` أو صفحة الهبوط التي بدأ منها.

## متغيرات البيئة (في Cloudflare، لا في الكود)

| المتغير | الوصف |
|---|---|
| `TAP_SECRET_KEY` | مفتاح Tap السري (`sk_test_…` للتجربة، `sk_live_…` للتشغيل) |
| `PUBLIC_BASE_URL` | اختياري، عنوان الموقع العام لمسار العودة والـwebhook |
| `ALLOWED_ORIGINS` | اختياري، أصول إضافية مسموحة، مفصولة بفواصل |

**لا تكتب أي مفتاح داخل المستودع ولا في المحادثات ولا في الصور.** يوضع من لوحة Cloudflare فقط. أي تغيير في المتغيرات يحتاج نشرًا جديدًا (Manage deployment ← Retry، أو commit جديد) حتى يسري.

## النشر

1. ارفع التعديلات إلى GitHub (الفرع الرئيسي).
2. Cloudflare Pages يبني تلقائيًا (المشروع `artvision-go`، مجلد الإخراج `public`).
3. افتح `/api/health` وتأكد أن `tap` تساوي `true`.
4. جرّب دفعة بمبلغ صغير قبل أي حملة.

## التشغيل المحلي والاختبار

```bash
node --test                # كل الاختبارات
node pricing-core.test.mjs # اختبارات التسعير فقط
```

## قبل تغيير أي شيء

- **السعر والحدود** تتغير في `pricing-core.mjs` فقط وبقرار Art، ثم تُولَّد الـWorker من جديد ويُشغَّل الاختبار.
- **لا خصومات ولا ندرة ولا عدّ تنازلي ولا ضريبة قيمة مضافة**: الشركة غير مسجلة فيها.
- طرق الدفع المعتمدة: مدى، Visa، Mastercard، Apple Pay، تمارا، تحويل بنكي. لا دفع عند الاستلام ولا Tabby.
- الهوية: العنابي `#841F48` والبيج `#E4CBBA` وخط ثمانية سانس.
- رضا العملاء: **98%** فقط، دون ربطه بمنصة أو مصدر.

## حالة تمارا

زر تمارا غير ظاهر حاليًا (`CFG.TAMARA=false` في الصفحة). التفعيل يتم من جهة تمارا مع Tap، ولا يُفعَّل الزر إلا بعد ظهور تمارا فعليًا في صفحة دفع Tap. إن لم تظهر، يضيف المطوّر زرًا مستقلًا بمصدر `src_tamara`.

## قيد معلّق

- التتبع (Pixel/CAPI) وتحديث سياسة الخصوصية قبل أي حملة مدفوعة.
- الصفحة الجذر `/` (قرار Art: بوابة، أو أرشفة الصفحة القديمة).
